CTF 零基础入门平台 · 调研结论

  • 日期：2026-10-15
  • 任务：找一个「零基础友好」的国内 CTF 基础入门学习平台
  • 结论一句话：首选 CTFHub 技能树（ctfhub.com）；教材用 Hello CTF（hello-ctf.com）；不要从攻防世界的新手练习区起步——那个入口已经下线了。

补充需求（第二轮）：用户表示更需要「介绍文档型」的资源。 → 见独立文档 ctf-reading-guide.html：主读 Hello CTF（免费开源、专为 0 基础写、2026-10-15 仍在更新），字典查 CTF Wiki，CTF-All-In-One 已停更两年（最后提交 2024-07-27）只当 PWN 补充；并给出零基础 1 周阅读顺序。 三者活跃度实测：Hello-CTF ⭐4257 / 最后提交 2026-10-15；ctf-wiki ⭐9704 / 2026-08-23；CTF-All-In-One ⭐4510 / 2024-07-27。

一、结论

主推：CTFHub —— 技能树

项 内容
入口 https://www.ctfhub.com/#/skilltree （先注册，支持手机号 / 邮箱 / 微信 / GitHub）
定位 平台自述「开箱即用的 CTF 学习解决方案」「降低 CTF 学习入门门槛」
为什么适合零基础 ① 全中文；② 把 Web/MISC 知识点拆成一棵「技能树」，一个节点 = 一个知识点，按顺序刷就是一条学习路线；③ 靶机在网页里点一下就开，零基础不用先装 Kali / Docker；④ 每题配官方 WriteUp，卡住有兜底；⑤ 覆盖 Web + MISC 两大入门方向，也有 Crypto / 杂项
费用 免费注册即可刷；平台用「金币」做激励（签到、基础题就能赚），个别题要金币解锁，不需要付费（注：未实际注册账号验证，遇到付费墙请反馈）

技能树 Web 方向的实际层级（据 CTFHub 官方 WriteUp 站 writeup.ctfhub.com/categories 的分类反推）：

Web
├─ Web前置技能 → HTTP协议（GET/POST/HEAD/请求头伪造…）
├─ 信息泄露   → 目录遍历 / PHPINFO / 备份文件下载 / Git泄露 / SVN泄露 / HG泄露
├─ 密码口令   → 弱口令 / 默认口令
├─ 文件上传   → 无验证 / 前端验证 / MIME绕过 / 00截断 / .htaccess …
├─ RCE        → 命令注入 / 过滤绕过 / 无参构造 …
├─ SQL注入    → 整数型 / 字符型 / 报错注入 / 布尔盲注 / 时间盲注 / 堆叠注入 …
├─ XSS / SSRF / XXE / 反序列化
└─ Web进阶   → JSON Web Token 等
另有：签到、基础知识、彩蛋（最容易上手，用来攒金币和找手感）

零基础起步动作（今天就能做） 1. 注册 → 先做「签到」「基础知识」两个节点（几乎不用技术，熟悉做题流程 + 攒金币）。 2. 按「Web前置技能 → 信息泄露 → 密码口令 → 文件上传 → RCE → SQL注入」的顺序从上往下刷，一个节点做完再进下一个。 3. 每题流程：看题 → 自己试 30 分钟 → 卡住点「提示」→ 还不行再去 https://writeup.ctfhub.com 搜同题 WP → 照着复现一遍，然后关掉 WP 重做一次。 4. 不要一上来碰 PWN / Reverse，先把 Web + MISC 刷出感觉。

必配教材（免费、专为 0 基础写）：Hello CTF

  • 入口：https://hello-ctf.com/hc-start/ （QuickStart / 新手村）
  • 免费开源、纯中文，明确写了「针对 0 基础新手编写」；本轮实测该站 2026-10-15 仍在更新（GitHub commits 显示 2026-10-14 提交）。
  • 里面有：CTF 是什么 / 五大方向怎么选 / 每个方向的前置知识 + 工具清单 + 现成题单（MISC 给的是 CTFshow 菜狗杯 + Web 入门；RE 给的是 NSSCTF HNCTF2022；PWN 给的是 pwn.college）。
  • 用法：先花 1 小时把它看完，再回 CTFHub 刷题。它不提供题目，是「说明书」。

二、备选平台（按推荐度）

平台 网址 适合谁 关键事实
青少年 CTF https://www.qsnctf.com/ 学生 / 预算为零 全公益免费；注册即得基础题目访问权限；含靶场 + 比赛（Web 50+、密码学 30+、逆向 40+ 题）
NSSCTF https://www.nssctf.cn/ 想按专题系统学 「工坊」是成体系的专题课（如 RE—Cheat Engine 5 题、PWN 二进制基础、Crypto—RSA）；题库含大量高校新生赛真题（SWPUCTF / HNCTF 等），对新手最友好的一类题；部分工坊要金币/付费
CTFshow https://ctf.show/ 想猛刷 Web 题 自称「萌新入门的好地方」，1500+ 原创题。注意：核心的 Web 入门 1000 题已转为 VIP 收费（全解锁 599.9 元 / 100 题一包 99 元），免费只剩「限免」的部分题
CTF2（原 BUUCTF） https://ctf2.dasctf.com/ 第二阶段 经典题库、WP 遍地，但难度混杂、没有梯度，不适合当第一个平台
CTF Wiki https://ctf-wiki.org/ 查知识点 知识库（不是刷题平台），当字典用

三、避坑（本轮实测，与网上大量过时攻略不一致）

  1. 攻防世界（adworld.xctf.org.cn）的经典「新手练习区」已经没了。 - 实测 https://adworld.xctf.org.cn/task?type=web&grade=0 → 站点 404 页（截图见 assets/evidence-adworld-404.png）；/challenges/list 同样 404。 - 现在站内导航「实训基地」指向 /all-course，内容是 AI实训 / 网安实训 课程（课程目录：Python程序设计、C语言、MySQL入门、Linux入门、密码学、二进制漏洞利用…），定位是课程+认证+赛事，不再是免费刷题场。 - 「历年真题」里的题是真实赛题（2024/2025 各大赛），且有部分是收费的（如「2024 河南天安杯」¥65、「熊猫杯」¥260）。 - → 结论：网上说「零基础先刷攻防世界新手区」的攻略已经过期，别照做。
  2. CTFshow 的入门题单不再是免费午餐。 官方 VIP 页明确写：VIP 会员解锁全部 1000 道 Web 入门题；分档购买 1-100 题也要 99 元。别以为注册就能刷 1000 题。
  3. 不要一开始就啃 PWN / Reverse。 Hello CTF 官方建议也是先从 Web / MISC 入手：Web 不需要系统底层知识，MISC 趣味性强、门槛低，用来熟悉比赛规则。
  4. 不需要先装 Kali。 Web 方向在浏览器里就能做题（F12 + HackBar 起步）；等做到文件上传 / 命令执行再上 Burp Suite Community（免费）和虚拟机。
